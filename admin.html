Cole o código do Apps Script
Na planilha: Extensões → Apps Script. Apague tudo, cole o código abaixo e ajuste no topo: EMAIL_ADMIN (seu e-mail) e API_KEY (chave Anthropic, só para leitura de PDF). Este é sempre o código mais atual do sistema.

3
Crie a coluna de módulos e chaves (automático)
Rode uma vez a função repair no editor do Apps Script, ou apenas publique — o sistema cria sozinho as abas e colunas que faltam (usuários, unidades, locais, chaves, movimentações).
4
Ative o e-mail diário de vencimentos
Ícone de relógio ⏰ (Gatilhos) → Adicionar gatilho → função verificarVencimentos · Temporizador por dia · 8h–9h.
5
Publique como app web
Implantar → Gerenciar implantações → editar (lápis) → Versão: Nova versão → Implantar. Executar como: você. Acesso: qualquer pessoa. A URL já está travada no sistema — republicando com a mesma implantação, a URL não muda. Se gerar URL nova, avise para atualizar.
6
Pasta de PDFs (automática)
Na primeira vez que anexar um PDF, o script cria sozinho a pasta "Contratos FHSL - PDFs" no Google Drive.
